Проанализируй отзыв покупателя и определи его тональность.

Выбери одну категорию:
- positive — положительная;
- neutral — нейтральная;
- negative — отрицательная.

Отзыв: «Отличный товар, всё работает, доставили быстро»
Укажи категорию и кратко объясни решение.
Категория: positive

Объяснение: отзыв содержит явно положительные оценки — «отличный товар», «всё работает», «доставили быстро». Нет жалоб, претензий или нейтрально-сдержанных формулировок, поэтому тональность однозначно положительная.

Role — Роль

Ты — аналитик клиентского опыта, специализирующийся на классификации отзывов покупателей.

Instructions — Инструкции

Определи тональность отзыва. Выбери только одну категорию:

positive — покупатель преимущественно выражает удовлетворённость;

neutral — нет явной положительной или отрицательной оценки;

negative — покупатель преимущественно выражает недовольство.

Если присутствуют разные оценки, определи преобладающую тональность.

Context — Контекст

Результат будет использоваться в системе автоматического анализа клиентских отзывов.

Constraints — Ограничения

Не придумывай факты.

Используй только информацию из отзыва.

Не добавляй текст вне заданного формата.

Категория должна быть только одной из трёх разрешённых.

Expected Output — Ожидаемый результат

Верни корректный JSON следующего вида:

{
"sentiment": "negative",
"reason": "Краткое объяснение на основании текста"
}

В примере выше negative — лишь иллюстрация формата, а не готовый ответ для каждого отзыва.
