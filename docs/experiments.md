# Журнал экспериментов

## Эксперимент 1: Классификация тональности отзывов

**Дата:** 30.10.2026
**Модель:** ChatGPT
**Данные:** datasets/reviews.csv (15 отзывов)

### Промты
- baseline.md: простой запрос без контекста и формата
- ricce.md: роль, контекст, алгоритм, ограничения, JSON-формат

### Результаты
| Метрика | Baseline | RICCE |
|---------|----------|-------|
| Всего отзывов | 15 | 15 |
| Правильных ответов | 0 | 13 |
| Ошибок | 15 | 2 |
| Неверный формат | 1 | 0 |

### Выводы
Базовый промт не сработал: модель вернула одно значение `neutral` на весь список, не обработав каждый отзыв. Улучшенный промт по RICCE дал структурированный JSON с ответами по каждому отзыву и обоснованиями. Две ошибки (id 6 и 14) — спорные случаи, где модель рассудила логично, но не совпала с ожидаемой разметкой.

### Что улучшить
- Добавить Few-shot примеры для сложных случаев (сарказм, смешанные эмоции).
- Проверить, как модель справится с 50 отзывами (проверка на большем наборе).
